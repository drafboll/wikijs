# Sauvegarde Veeam vers Amazon S3

## Pré-requis
 
- Un compte AWS actif
- Un bucket S3 créé (ex : `veeam-backup-alpha`)
![capture_d'écran_2025-07-12_231307.png](/s3/capture_d'écran_2025-07-12_231307.png)

---

## 1. Création de l'utilisateur IAM pour Veeam

1. Accéder à la console AWS > **IAM** > **Utilisateurs**
2. Cliquer sur **Créer un utilisateur** et nommer par exemple `veeam-user`
![capture_d'écran_2025-07-12_231326.png](/s3/capture_d'écran_2025-07-12_231326.png)
3. Attribuer la politique **AmazonS3FullAccess**
![capture_d'écran_2025-07-12_231337.png](/s3/capture_d'écran_2025-07-12_231337.png)
4. Générer les **clés d’accès** (Access Key ID + Secret Key)
5. Noter ces clés en lieu sûr (elles seront utilisées dans Veeam)

---

## 2. Création d’un compartiment S3

1. Se rendre dans la console AWS > **S3**
2. Cliquer sur **Créer un compartiment**
3. Nom du compartiment : `veeam-backup-alpha`
4. Choisir la région : ex. `US East (N. Virginia)`
5. Laisser les options par défaut (ou désactiver le blocage d’accès public si nécessaire)
6. Créer le compartiment

---

## 3. Configuration d’un dépôt de stockage objet dans Veeam

1. Lancer **Veeam Backup & Replication**
2. Aller dans **Backup Infrastructure** > **Object Storage Repositories**
3. Cliquer sur **Add Object Storage Repository**

### Étapes :

#### Name

- **Name** : `AWS S3 - backup`
- **Description** : Facultative
![capture_d'écran_2025-07-12_231359.png](/s3/capture_d'écran_2025-07-12_231359.png)

#### Account

- **Credentials** : Ajouter les clés AWS (Access Key ID + Secret Key)
- **Region** : `Global` (ou `us-east-1` selon ton bucket)
- **Connection mode** : `Direct`
![capture_d'écran_2025-07-12_231407.png](/s3/capture_d'écran_2025-07-12_231407.png)

#### Bucket

- **Bucket name** : `veeam-backup-alpha`
- **Folder** : `test` (ou autre nom de dossier logique)
- (Laisser les autres options par défaut)
![capture_d'écran_2025-07-12_231419.png](/s3/capture_d'écran_2025-07-12_231419.png)

#### Mount Server

- Choisir le serveur de montage par défaut (ex : `SVR-VEEAM-01`)
![capture_d'écran_2025-07-12_231459.png](/s3/capture_d'écran_2025-07-12_231459.png)

#### Apply

- Vérification et enregistrement des paramètres
- Le dépôt est créé avec succès

---

## 4. Création d’un job de sauvegarde vers S3

1. Aller dans **Home > Jobs > Backup Job**
2. Cliquer sur **Add Job > Virtual Machines**

![capture_d'écran_2025-07-12_231513.png](/s3/capture_d'écran_2025-07-12_231513.png)
### Name

- **Nom** : `Backup Job S3`
- **Description** : Facultative


### Virtual Machines

- Ajouter une ou plusieurs VMs à sauvegarder (ex : `ZEX-SVR-ZABBIX-03`)

### Storage

- **Backup repository** : `AWS S3 - backup`
- **Retention policy** : 7 jours (modifiable)
- Laisser les options par défaut
![capture_d'écran_2025-07-12_231530.png](/s3/capture_d'écran_2025-07-12_231530.png)

### Guest Processing

- Activer si nécessaire (ex. sauvegarde VSS)

### Schedule

- Définir la planification (ex : chaque nuit)

### Summary

- Vérifier les paramètres
- Lancer manuellement la première sauvegarde si besoin

---

## 5. Vérification de la sauvegarde

### Sur Veeam :

- Aller dans **History > Jobs**
- Vérifier que la sauvegarde s’est bien déroulée

### Sur Amazon S3 :

- Ouvrir le compartiment `veeam-backup-alpha`
- Naviguer dans le chemin configuré (ex. `Veeam/Backup/test/`)
- Les objets sont présents sous forme de fichiers non lisibles directement (format Veeam)

---

## Remarques importantes

- Le contenu sur S3 est **chiffré et structuré pour Veeam** (pas lisible en clair)
- Les sauvegardes ne sont **pas visibles en tant que fichiers standards** dans S3
- Penser à définir une stratégie de rétention pour ne pas saturer l’espace
- Vérifie les permissions IAM si tu ne vois pas les fichiers dans l’interface web
